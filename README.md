# kintore-log

筋トレの記録を管理するシンプルなWebアプリです。日々のトレーニング内容(種目・重量・回数)を記録し、履歴の確認や種目ごとの推移グラフでトレーニーの成長を可視化します。

## 主な機能

- トレーニング記録の追加(日付・種目名・セットごとの重量と回数・メモ)
- 記録の履歴一覧(日付ごとにグループ表示)、編集・削除
- 種目を選んで最大重量・総重量(ボリューム)の推移をグラフで表示
- データはブラウザの localStorage に保存(サーバー不要)

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Recharts

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## ゴルフスコア記録 (`/golf/`)

スマホでラウンド中に使える、ゴルフのスコア記録ページです(`public/golf/index.html` の単体ファイル)。

- 1打ごとに大きな「打った！ +1」ボタンを押すだけ。いまの打数と「次は何打目か」が常に表示されます
- 間違えたときは「−1 取り消し」、連打による二重カウントは自動で無視
- ホール移動、PAR(3/4/5)の変更、スコア表(前半・後半・合計)、過去ラウンドの保存
- 打数は押すたびに自動保存。画面を閉じても、開き直すと続きから再開
- Service Worker(`public/golf/sw.js`)で一度開いたあとは電波がなくても起動
