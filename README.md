# kintore-log

筋トレの記録を管理するシンプルなWebアプリです。日々のトレーニング内容(種目・重量・回数)を記録し、履歴の確認や種目ごとの推移グラフでトレーニーの成長を可視化します。

## 主な機能

- トレーニング記録の追加(日付・種目名・セットごとの重量と回数・メモ)
- 記録の履歴一覧(日付ごとにグループ表示)、編集・削除
- 種目を選んで最大重量・総重量(ボリューム)の推移をグラフで表示
- データはブラウザの localStorage に保存(サーバー不要)

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Recharts

## セットアップ

```bash
npm install
npm run dev
```
